## Agent skills

### Issue tracker

Issues live as local markdown files under `.scratch/<feature>/issues/` (no remote). See `docs/agents/issue-tracker.md`.

### Triage labels

The five default labels, recorded as a `Status:` line in each issue file. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `GLOSSARY.md` and `docs/adr/` at the root, created only when needed. See `docs/agents/domain.md`.
